# 界面语言（i18n）

## 使用

设置 → 外观 → 界面语言：

- 简体中文（`zh-CN`，源语言）
- English（`en-US`）

切换后立即生效，并写入 `settings.json` 的 `language` 字段；下次启动沿用。

## 添加其他语言

在 `config/locales/` 放入一个 JSON 文件，例如 `ja-JP.json`：

```json
{
  "code": "ja-JP",
  "name": "Japanese",
  "nativeName": "日本語",
  "dir": "ltr",
  "title": "Astral Realm",
  "messages": {
    "设置": "設定",
    "新对话": "新しい会話",
    "发送": "送信"
  }
}
```

- `code`：BCP 47 风格语言代码；文件名可以任意，但 code 必须唯一。
- `name` / `nativeName`：设置里的显示名称；`nativeName` 优先。
- `dir`：`ltr` 或 `rtl`，会写到 `<html dir>`。
- `title`：窗口标题。
- `messages`：中文源字符串 → 目标语言；找不到的键自动回退中文。

`app/locales/` 是内置语言，`config/locales/` 会覆盖同 code 的内置文件。新增 JSON 不需要改代码，也不需要重新构建。

## 运行时接口

渲染层暴露：

```js
window.Astral.i18n.t('发送')
window.Astral.i18n.setLocale('en-US')
window.Astral.i18n.availableLocales()
window.Astral.i18n.registerLocale(
  { code: 'ko-KR', name: 'Korean', nativeName: '한국어', dir: 'ltr' },
  { '设置': '설정', '发送': '보내기' }
)
window.Astral.i18n.onLocaleChange((code) => {})
```

插件或外部语言包可以调用 `registerLocale` 注册临时语言；需要跨重启保留的语言请放入 `config/locales/`。

## 范围与回退

- 静态 UI 由 DOM 本地化器处理，动态文案走 `t()`。
- 聊天正文、Markdown、代码、用户输入、项目名和成员名不会自动翻译。
- 当前英文包先覆盖主壳、输入区、任务/上下文、设置导航与外观、新会话和常用操作；未收录的模块文案自动保留中文，后续只需补 `messages`，不需要改架构。
- 主进程的托盘菜单和常用原生对话框按钮也读取同一份语言文件。

## 新增源文案

源语言是中文。新增界面文案时：

1. 直接写中文（源语言）；
2. 在 `app/locales/en-US.json` 的 `messages` 里加一行中文 → 英文；
3. 动态文案用 `t('中文源文案', { name })`，不要拼接后再翻译。

如果某段文字不应被 DOM 本地化器处理，给它加 `data-i18n-skip`。
